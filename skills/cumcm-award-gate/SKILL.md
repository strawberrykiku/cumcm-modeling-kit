# 国赛交卷前质控关卡

> 轻壳版：一个人、一个对话就能跑完，不需要多 agent 编排。
> 定位：solver（解题）→ paper（写作）→ **本关卡（把关）** 三段式的最后一环。
> 它不产生内容，只拦住会让你掉档的漏洞——真正的分靠前两步的内容质量。

## 什么时候用

- **交卷前必跑**：初稿或终稿完成后，逐条过"强制自查清单"（第二部分）。
- **建模时植入**：在 solver 选模/求解阶段，顺手落实"创新账本"和"头条数字稳健性"（第一部分）。
- **想要客观分数**：用"盲评自评协议"（第三部分）给论文独立打分，看还差国一多远。

## 怎么用（轻壳原则）

1. 你（助手）拿到用户的论文/草稿，**对照清单逐条判定**：✅ 通过 / ⚠️ 存疑 / ❌ 不通过。
2. 每个 ❌ 必须给出：**在哪、为什么不行、怎么改**。不要只报"有问题"。
3. 不要一次性铺满所有条目就完事——**发现 ❌ 就停下让用户改，改完再继续**，像真人指导老师一样盯着。
4. 时间紧时的优先级：第二部分的 **A（摘要）+ D（模型检验）+ F（代码可复现）** 是掉档重灾区，先保这三块。

## 第一部分：建模阶段的两个"够国一"要求

这两条要在 solver 阶段就落实，不是最后补。它们是国二和国一的分界线。

### 1.1 创新账本（Innovation Ledger）

**教科书式套用标准模型，封顶国二，到不了国一。** 所以每道题至少要命名并守住一个"评委在别的队没见过"的贡献。在下列五类里至少坐实一类：

- 给标准模型加一个**非显然的机理或耦合**
- 给出一个**解析结果**（闭式解、界、结构性质），而别人只会仿真
- 把两个方法做**非显然的融合**，得到单用一个给不了的东西
- 做一个**比题目要求更难的扩展**，答出别人跳过的子问题
- 一个**比标准做法更锋利的检验/可识别性/决策稳健性论证**

给每个贡献写一句话：**"为什么评委看到会坐直身子"**，并说明它加强了哪个要求。

**红线**：如果你能做到的只有"正确套用了标准模型"，就**如实标注为『封顶国二』风险**，别把教科书工作伪装成创新。合成/仿真数据题里，"复现或匹配了数据生成过程"**不许**当作头号创新点——贡献必须是生成过程没有直接给你的东西。

### 1.2 头条数字稳健性

每个**关键结论数字**（最优目标值、推荐方案、临界阈值、绑定约束值）都要对**最没把握的参数**做压力测试，而不只对好估计的参数。

**红线**：如果一个绑定约束刚好贴着阈值（例如安全下限 0.90、你只做到 0.902），必须报告：在控制它的每个参数的合理区间/置信区间内，这个"可行"结论**还成不成立**。一个建立在最没把握参数上、又没检验的头条数字，是实打实的掉档风险，要主动暴露、不要埋进脚注。

## 第二部分：交卷前强制自查清单

逐条过。每条给出 ❌ 的判定口径。

### A. 摘要（第一决定项，评审第一轮就看它）
- ❌ 摘要里**有子问题只写了方法、没有量化结果**。红线："每问必有一数"——每个子问题至少一个具体数字（最优值、R²、误差、提升幅度……）。
- ❌ 结果只给范围或定性描述，不给精确值。
- ❌ 摘要没有体现总体思路或关键结论。
- ✅ 参考结构：背景 1 句 → 总体思路 1 句 → 每问（方法 + 量化结果）→ 检验/亮点 1-2 句 → 关键词 3-5 个。

### B. 完整性（题目覆盖）
- ❌ 题目里**有要求没有对应的输出/回答**（最常见的掉档原因之一）。逐条对照题目每一问。
- ❌ 有子问题只做了定性讨论，没给出题目要的具体结果。

### C. 建模质量
- ❌ 问题分析写成"我们将用 A 方法做 X"的方法罗列，没讲**为什么选这个模型、淘汰了哪个备选**。
- ❌ 选了模型但正文/摘要没有一个可辨认的创新点（对照 1.1），也没标注封顶风险。
- ❌ 公式直接抄教科书通用式，没做本题适配、符号没对应到本题变量。
- ❌ 有假设是废话（"数据真实可靠""忽略偶然因素"），或有假设后文根本没用到。

### D. 模型检验（国二→国一的分水岭）
- ❌ **有子问题完全没有灵敏度分析或误差分析**。至少对关键参数做 ±10%/±20% 扰动看结果变化。
- ❌ 报了结果但没有任何误差指标（MSE/MAE/R² 之类）或稳健性讨论。
- ⚠️ 只有一处集中的检验、其他子问题裸奔——建议每个子问题末尾都嵌一小段检验。

### E. 结果表达
- ❌ **有图/表后面没有解释**。红线：每个图表后要有 1-3 句"这结果是什么、为什么会这样、对题目意味着什么"。
- ❌ 图表有渲染缺陷（标签重叠、坐标轴被裁、字看不清、图题重复）。→ 用第四部分的 figqa.py 查。
- ⚠️ 问题分析里没有整体建模流程图（获奖论文约 70% 有）。

### F. 代码与可复现（2026 国赛规则：缺必要源程序或程序不能运行，可能取消评奖资格）
- ❌ 附录代码不完整、或根本跑不起来。
- ❌ 论文声称的方法和代码实现**不一致**（说用 XGBoost，代码跑的是线性回归）。
- ❌ 代码没有分节注释标明对应哪个子问题。

### G. 规范与格式
- ❌ 参考文献 < 6 条，或引用了 CSDN/知乎/百度百科/AI 工具等非学术来源。
- ❌ 正文里引用了的文献没列出，或列了的没在正文出现。
- ❌ 公式/图表编号不统一；表题不在上方、图题不在下方；符号说明缺项。

### H. 匿名性（国赛盲评硬要求）
- ❌ 正文/页眉/页脚/文件属性里出现**学校、姓名、指导教师、学号、联系方式**。→ 用第四部分的 pdf_qa.sh --anonymous 扫。
- ✅ 只在指定位置填报名编号/赛区编号。

**自查结论**：给出 ✅ 通过 / ⚠️ 有条件通过 / ❌ 不通过。若为 ❌，改完重跑相关条目。

## 第三部分：盲评自评协议

清单过完，用这个给论文一个**不带偏见的分数**。

**关键：另开一个全新对话做这件事。** 写论文的上下文会"觉得自己写得好"，换一个干净上下文、只喂 PDF + 下面的标准，才拿得到接近真实评审的独立视角。

操作：
1. 新对话里只贴入**编译好的 PDF**（或全文），加下面这段评分指令。
2. 让它对 5 个维度各打 0-100，按权重算加权总分，映射到档位。
3. 让它指出**"如果只能改一件事，改什么"**。

评分维度与权重：

| 维度 | 权重 | 看什么 |
|---|---|---|
| 摘要 | 0.25 | 每问有量化结果、思路清、可读 |
| 建模 | 0.25 | 模型合理、有创新、公式有本题针对性 |
| 结果 | 0.20 | 结果正确合理、有解释、图表支撑 |
| 写作 | 0.15 | 结构清晰、表达规范、无 AI 味 |
| 完整性与可复现 | 0.15 | 覆盖所有问、代码完整可跑 |

档位（对照真实稀有度：国一约前 5-8%，别给自己放水）：

| 目标档 | 加权总分 ≥ | 单项不低于 |
|---|---|---|
| 国一 | 85 | 70 |
| 国二 | 75 | 60 |
| 国三 | 65 | — |

任何一个单项低于目标档的下限，即使总分够也不算达标——去补那个短板。

**诚实提醒**：AI 自评和真人评审共享一部分盲区，85 分不是保证。它的价值是暴露方向（哪个维度最弱、那"一件事"是什么），不是发奖状。有条件一定让真人（队友/学长/老师）再看一遍。

## 第四部分：图表与 PDF 自动检查脚本

两个脚本在本 skill 的 `scripts/` 下，直接执行、不要重写。

### figqa.py —— 图表缺陷检查（标签重叠 / 坐标裁切）

它是一个**库**，不是命令行工具（`--self-test` 只用于自检）。用法是把它 import 进你的画图代码，画完图存盘前断言无碰撞：

```python
import sys; sys.path.append("scripts")   # 指到 figqa.py 所在目录
from figqa import assert_no_overlap
# ... 画完 fig 之后、savefig 之前：
assert_no_overlap(fig)     # 有标签重叠/裁切会直接抛错，逼你修
fig.savefig("problem1_result.pdf")
```

把 figqa.py 一起放进附录代码目录，评审复现时也能跑。依赖 matplotlib。

### pdf_qa.sh —— 编译后 PDF 检查

对**最终编译出来的 PDF** 跑（不是源文件）：

```bash
bash scripts/pdf_qa.sh 你的论文.pdf --anonymous
```

它查：页数、重复图题（Figure N / 图 N）、**匿名性**、空白页。
- 国赛没有美赛那种 25 页硬上限，一般不用加 `--max-pages`；如果你赛区有页数要求，再加 `--max-pages N`。
- **`--anonymous` 对国赛很关键**——它会抓 PDF 属性里残留的中文姓名、正文第 1 页里的"姓名/指导教师/学校"字样和邮箱。
- 依赖 poppler-utils（`pdfinfo/pdftoppm/pdftotext`）；缺了脚本会提示怎么装。

自检两个脚本是否可用：

```bash
python3 scripts/figqa.py --self-test
bash    scripts/pdf_qa.sh --self-test
```
