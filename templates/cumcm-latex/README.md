# 国赛 LaTeX 论文模板（匿名版 · 对齐官方规范）

已按《全国大学生数学建模竞赛论文格式规范（2026 年修订稿）》固化格式。**你不需要在本机装 LaTeX**——用 Overleaf 在线编译即可。

## 用法（Overleaf，推荐）

1. 打开 [overleaf.com](https://www.overleaf.com) → New Project → Blank Project。
2. 把 `main.tex` 的内容整体粘贴进去（或直接上传本文件）。
3. 左上 **Menu → Compiler** 选 **XeLaTeX**（必须，含中文）。
4. 点 Recompile，**连编两次**（生成页码与交叉引用）。
5. 之后按 `math-modeling-paper` skill 依次输出的 `.tex` 代码块，逐块替换模板里的占位内容。

本机若已装 TeX Live / CTeX，也可 `xelatex main.tex` 连编两次。

## 模板已固化的官方要求

无需你手动设置，导言区已处理：

- A4、上下左右页边距均 2.5 cm
- 电子版首页即摘要页；**无承诺书、编号页、封面、目录**
- 页码从摘要页起为第 1 页，**页脚居中**
- 题目黑体 18pt；摘要标题黑体 16pt；一级/二级/三级标题黑体 16/14/12pt
- 正文宋体 12pt、**1.25 倍行距、首行缩进 2 字符**、两端对齐
- **图题在图下方、表题在表上方**，均宋体 10.5pt 居中；三线表（booktabs）
- 公式居中、**编号右对齐**，正文用 `由式~(\ref{eq:xxx}) 可得` 引用
- 参考文献、附录正文宋体 10.5pt
- **AI 工具使用声明置于参考文献之前**
- 附录含**支撑材料文件清单**

西文字体优先 Times New Roman，缺失时自动回退到度量兼容的 TeX Gyre Termes（Overleaf 自带）。

## 你需要填/改什么

- **题目**：准确概括研究对象与任务，别写成「2025 年数学建模 A 题论文」。
- **摘要**：按「总述 + 分问 + 检验 + 总结」写，**每问必须给出关键量化结果**；不放公式图表；最后定稿。
- **各章**：按注释里的规范提示写；`数据处理`、`模型推广` 两章按需，**没内容就整章删掉**。
- **图片**：放进 Overleaf 项目的 `figures/` 目录，取消 `\includegraphics` 那行的注释。
- **参考文献**：按正文首次出现顺序编号，正文标注与条目一一对应。
- **附录**：列出支撑材料清单 + 完整可运行代码。没程序须写明「本论文没有用到程序」。

## 交卷前必查（红线）

- **匿名**：全文不得出现姓名、学号、联系方式、指导教师、学校/学院/赛区，以及可识别身份的路径与水印。
- **占位符**：全文搜索并删除 `……`、`XXX`、`此处插图`、`待补充` —— 规范明令不得出现。
- **篇幅**：摘要 ≤ 1 页；正文 ≤ 30 页且无目录；PDF ≤ 20 MB。
- 图表必须在正文中被引用并解释；数值必须带单位。

匿名性可用 kit 的脚本扫一遍（需 poppler-utils）：

```bash
bash ../../skills/cumcm-award-gate/scripts/pdf_qa.sh 你的论文.pdf --anonymous
```

## 常见坑

- **中文不显示 / 报错**：Compiler 没选 XeLaTeX。
- **附录代码里的中文注释变方块**：等宽字体缺中文字形 —— 代码注释用英文。
- **页码、引用显示为 `??`**：只编译了一次 —— 再编译一次。
- **图片找不到**：`\includegraphics` 的路径要与 Overleaf 里的实际目录一致。
