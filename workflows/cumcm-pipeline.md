# 国赛数学建模 · 三段式流程（轻壳版）

> 一个对话从拿到题目走到交卷。三个 skill 接力：solver → paper → award-gate。
> 每段末尾**停下等你确认**，不要一口气跑到底——你要能讲清楚你提交的每一步。

## 总览

```
拿到赛题
  │
  ▼
① math-modeling-solver（解题）
  ├ 阶段1   拆题：判定每个子问题的数学本质（12 类）
  ├ 阶段1.5 文献检索（可跳过，硬上限 5 次搜索）
  ├ 阶段2   选模：查决策矩阵 + 至少 2 个候选 + 落实【创新账本】
  ├ 阶段3   求解：公式推导 + 伪代码 + 可运行代码 + 落实【头条数字稳健性】
  └ 阶段4   论文衔接 → 输出 [PAPER_READY] 草稿片段
  │
  ▼
② math-modeling-paper（写作）
  ├ 逐章写作（摘要 / 问题分析 / 建模求解 / 检验 / 评价……）
  └ 交付前四轮自审 + 去 AI 味
  │
  ▼
③ cumcm-award-gate（把关）
  ├ 交卷前强制自查清单（A 摘要 / B 完整性 / C 建模 / D 检验 / E 结果 / F 代码 / G 规范 / H 匿名）
  ├ figqa.py 查图表缺陷 + pdf_qa.sh --anonymous 查 PDF 匿名性
  └ 盲评自评（新对话独立打分，看差国一多远）
  │
  ▼
交卷
```

## 三个"够国一"的贯穿要求

从头贯穿到尾，不是最后补：

1. **每问必有一数**（摘要）——阶段 3 / 写作时就盯着。
2. **创新账本**——阶段 2 选模时命名至少一个非平凡贡献，否则如实标注"封顶国二"。
3. **头条数字稳健性 + 每问都有检验**——阶段 3 + 写作时嵌入，这是国二→国一的分水岭。

## 每段的停留确认点

- solver：每阶段末尾停留，确认后再进下一阶段；发现模型不合适可回退重选。
- paper：逐章写，每章先讲"目的 → 结构 → 写什么 → 红线"。
- award-gate：发现 ❌ 就停下改，改完再继续。

## 72 小时时间盒建议（新手参考，非硬性）

| 时段 | 干什么 |
|---|---|
| 第 1 天上午 | 读题、选题、阶段 1 拆题 + 阶段 1.5 快速查文献 |
| 第 1 天下午–晚上 | 阶段 2 选模 + 阶段 3 第一问建模求解 + 出代码 |
| 第 2 天 | 阶段 3 其余子问题 + 检验（灵敏度/误差）+ 开始写作 |
| 第 3 天上午 | 写完初稿 |
| 第 3 天下午 | award-gate 过清单 + 修图表 + 盲评自评 + 定稿 |
| 交卷前 2 小时 | pdf_qa.sh --anonymous 扫匿名性 + 确认代码能跑 + 导出 PDF |

摘要留到最后写——等结果都出来了，才写得出"每问一数"。

## 新手最容易踩的 5 个坑（对应清单）

1. 摘要只写方法不写数字 →（清单 A）
2. 漏答了题目某一小问 →（清单 B）
3. 每问都没做灵敏度/误差分析 →（清单 D，最伤）
4. 附录代码跑不起来、或和论文不一致 →（清单 F，可能直接取消资格）
5. 论文里漏了学校/姓名没匿名 →（清单 H）

## 排版成 PDF

论文正文写完后，用仓库自带的 `templates/cumcm-latex/main.tex`（匿名版国赛模板）排版：把各章内容填进去，用 **XeLaTeX 连编两次**。编译说明与依赖见 `templates/cumcm-latex/README.md`。交卷前用 `cumcm-award-gate` 的 `pdf_qa.sh --anonymous` 扫一遍匿名性。

## 安装与加载

见仓库根目录 `README.md`。三个 skill 装到 `~/.claude/skills/` 后，Claude Code 会按各自 description 在合适的时候自动加载。
